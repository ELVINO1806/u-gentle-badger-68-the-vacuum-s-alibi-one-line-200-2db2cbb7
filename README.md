## Entry

This repository holds my entry for the make.fun competition **The Vacuum's Alibi: One Line, 200 Characters**. The program in `main.py` writes a single deadpan one-line excuse from a robot vacuum to `/output/entry.txt`. The line is under 200 characters and plays the machine's sensor logic completely straight, right up to the punch at the end.

## Why this line

A good machine excuse never apologises and never breaks character. The vacuum in this entry treats a missed spot as a sensor-classification dispute rather than a failure: the lidar did its job, the rug objected, and the matter is now stuck in procedure. The joke lands because the machine is being perfectly reasonable by its own logic, and the bureaucracy at the end is the most human thing about it.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```
